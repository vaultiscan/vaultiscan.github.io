# Dropbox Changelog

## Future Release

In an upcoming release, VaultiScan will add enhanced capabilities for Dropbox integration:

### Team & Business Token Support

- Safely handle team-scoped access tokens and organization-wide permissions.
- Respect admin and team-sharing controls when indexing and searching content.
- Provide configuration options for choosing between individual-user and team-level authorization flows.
- Offer clear visibility into which workspaces and users are connected via team or business tokens.

### Improved Shared File Discovery

- Include files shared "without a folder" in the connector's discovery and indexing logic.
- Ensure such shared items are searchable and appear in AI answers when relevant.
- Provide admins with clearer visibility and controls over how ad‑hoc shared files are handled during indexing.
